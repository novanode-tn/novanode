# Novanode

French coming-soon site for Novanode, built with Next.js. The visual system follows the Violet Connection board: violet `#7047EB`, ink `#17151E`, off-white `#F7F5FA`, tint `#E8DFFB`, Manrope for display, Inter for text.

Canonical URL defaults to `https://novanode.tn`. Override it with `NEXT_PUBLIC_SITE_URL` before deploy.

```bash
npm run dev
npm run build
```
